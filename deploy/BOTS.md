# 机器人接入（用户自助，三种渠道）

不再由服务端集中配置，每个用户在网页「设置 → 机器人接入」里接入自己的渠道。
服务端只需设 `AM_PUBLIC_URL`（拼回调地址用，默认 https://monitor.vita-llm.com）。

## 1. 钉钉群机器人 · 主动推送（个人号零资质）

会话状态变化（等待输入 / 结束 / 新会话 / 设备上线离线）推到你的钉钉群。

- 钉钉建群 →「智能群助手 → 添加机器人 → 自定义（Webhook）」→ 安全设置选「加签」
  （拿 SEC 密钥）→ 复制 Webhook 地址；
- 网页「设置 → 机器人接入 → 钉钉群机器人」填 Webhook + 加签密钥 + 勾事件 →「保存并测试」。

## 2. 企业微信自建应用 · 双向遥控

在企业微信里发指令遥控（会话 / 暂停 N / 发 N 内容 …）。需企业微信（个人可注册未认证）。

- 网页「设置 → 机器人接入 → 企业微信自建应用」填 CorpID / Token / EncodingAESKey
  →「保存并生成回调地址」→ 复制回调地址；
- 企业微信管理后台 → 自建应用 →「接收消息 → 设置API接收」，URL 填回调地址、
  Token/AESKey 填同样的值、加解密选安全模式 → 保存（会即时验证）。

## 3. 钉钉企业应用 · 双向遥控

在钉钉里 @机器人 发指令。需钉钉组织（个人可建未认证）+ 开放平台企业内部应用。

- 网页「设置 → 机器人接入 → 钉钉企业应用」填应用 AppSecret →「保存并生成回调地址」；
- 钉钉开放平台 → 企业内部应用 → 机器人 →「消息接收模式」选 HTTP，回调 URL 填回调地址。

## 说明

- 回调地址里带你专属的不透明 channel，回调进来即以你的账号身份执行指令（URL 即绑定）。
- 密钥类字段（AESKey / AppSecret / 加签密钥）0600 落盘、不回传前端。
- 双向采用同步/被动回复，无需 access_token。
