# 终端任务监控 · 桌面客户端

Mac / Windows 各一个应用程序，**零配置**：安装 → 打开 → 在窗口里登录你的账号，
本机即自动绑定并建立链接。网页、移动端与你的其他客户端上，立刻能看到这台电脑
终端里正在跑的 AI 编码代理会话（Claude Code / Codex / Gemini CLI 等）。

- 关闭窗口默认**缩小到系统托盘**，后台持续同步；托盘右键菜单可改为「关闭即退出」。
- 「设备管理」里的**信任开关就是链接开关**：撤销信任即断开这台设备的同步，随时可恢复。
- 有新版本时托盘会出现「⬆ 新版本可用」，点击即到官网下载。

---

## macOS

从官网下载 `终端任务监控.dmg` → 打开后把 App 拖进「应用程序」→ 启动
（首次若被拦截：右键 App →「打开」）→ 在窗口里登录，完成。

- 正常应用：Dock 有图标、可 Cmd-Tab；缩到托盘后 Dock 图标隐藏、菜单栏图标常驻。
- 托盘右键：连接状态 / 显示窗口 / 在浏览器打开 / 关闭时最小化到托盘 / 开机自启 /
  监控范围（勾选某终端=不监控它）/ 退出。

## Windows

从官网下载 `终端任务监控.exe`（**中文安装向导**）并运行
（若弹「Windows 已保护你的电脑」：更多信息 → 仍要运行）→
按向导选择安装位置、是否创建桌面图标、是否开机自启 → 完成后启动，
在窗口里登录，完成。

- 托盘图标在右下角；左键开窗口，右键菜单与 macOS 相同。
- 开机自启：安装向导里可勾选；装完后在客户端「设置 → 设备管理 → 本机客户端」
  或托盘菜单里也能随时改。
- 卸载：「设置 → 应用」里卸载，或开始菜单「卸载 终端任务监控」。

## Android

从官网下载 `终端任务监控.apk` 安装。App 内即完整前台，登录后即可查看与控制
你名下全部设备的会话；站点功能更新对 App 即时生效，App 本体有新版时应用内会提示。

## 常见问题

- **登录后没看到本机设备**：等 2~3 秒；仍没有则重启客户端（会重新发起绑定）。
- **想停掉某台电脑的同步**：前台左下角头像 → 设备管理 → 撤销信任（或直接删除设备；
  删除后那台客户端会自动回到「待绑定」状态，重新登录即可再次接入）。
- **高级：自建 hub**：客户端默认连接官方站点；自建服务时在
  `config.txt`（macOS 在 App 包内 `Contents/Resources/`，Windows 与 exe 同目录）
  写 `AM_HUB_URL=你的地址` 即可。此文件正常使用**无需存在**。
