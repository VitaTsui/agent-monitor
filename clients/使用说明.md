# 监控客户端使用说明

把你这台电脑上正在跑的 Claude Code 会话上报到 **https://monitor.vita-llm.com**，
就能在网页上实时查看和控制（暂停 / 恢复 / 中断 / 发布任务）。

## 前提

- 这台电脑装了并用过 **Claude Code**（客户端读取 `~/.claude/projects` 下的会话）。
- 你在 https://monitor.vita-llm.com 上已有账号（默认 `admin`，或管理员给你新建的账号）。

## macOS（`mac/` 目录）

1. 用文本编辑器打开 `启动监控.command`，把 `AM_USER="admin"` 改成**你的登录用户名**，保存。
2. 双击 `启动监控.command`。
   - 首次可能被拦截：**右键点它 → 打开**，或到「系统设置 → 隐私与安全性」点「仍要打开」。
3. 出现「正在连接…」即已开始上报。**保持这个终端窗口开着**就持续上报，关掉即停止。

> 二进制是 arm64 + Intel 通用版，任意 Mac 都能跑。

## Windows（`windows/` 目录）

1. 用记事本打开 `启动监控.bat`，把 `set AM_USER=admin` 改成**你的登录用户名**，保存。
2. 双击 `启动监控.bat`。
   - 首次可能弹「Windows 已保护你的电脑」：点**更多信息 → 仍要运行**。
3. 出现「正在连接…」即已开始上报。**保持这个黑窗口开着**就持续上报，关掉即停止。

## 接入后：去网站信任本设备

第一次接入时，设备处于「待信任」状态，**会话不会立刻显示**（隐私保护）。
到 https://monitor.vita-llm.com/portal → 左下角头像 →「设备管理」→ 找到你这台电脑 →
点「信任」。之后它的会话就会出现在左侧列表里。

- 你只能看到**自己名下、且已信任**的设备（`AM_USER` 决定归属哪个账号）。
- 换台电脑就把对应的 `mac/` 或 `windows/` 目录整个拷过去，同样改 `AM_USER` 再运行。

## 常见问题

- **左侧一直「暂无设备」**：确认脚本窗口没报错、`AM_USER` 填的是真实存在的账号；等 2~3 秒刷新。
- **设备在线但没有会话**：该电脑当前没有正在运行的 Claude Code 进程；跑一个 `claude` 就会出现。
- **想开机自启/后台常驻**：本目录的脚本版是「开着窗口才上报」。改用同级的托盘版即可
  （macOS 用 `mac-app/`、Windows 用 `windows-app/`）：双击即驻留、关窗口不退出、
  托盘右键菜单里可勾选「开机自启」。详见 [桌面版使用说明.md](桌面版使用说明.md)。

## 令牌说明

脚本里已内置 `AM_AGENT_TOKEN`（设备接入令牌）——这是这套监控的部署凭据，
**别把脚本发到公开渠道**。令牌泄露可让他人伪造设备接入；真泄露了让管理员轮换即可。
