# 终端任务监控 · 桌面客户端

Mac / Windows 各一个应用程序（`mac-app/`、`windows-app/`）。安装后像普通软件一样使用：
打开是完整的网站前台（设备、会话、对话、设置、git 对比全都有），关掉窗口可选
**直接退出**或**缩小到系统托盘**——缩到托盘后程序在后台持续运行，**不间断地把本机
Claude Code 会话同步到 https://monitor.vita-llm.com**。

---

## macOS（`mac-app/`）

**安装**：双击 `安装.command` —— 自动装进「应用程序」、去除隔离、启动。
（若被拦截：右键 `安装.command` →「打开」。）
或手动：把 `终端任务监控.app` 拖进「应用程序」，首次右键 App →「打开」过一次 Gatekeeper。

**用法**：
- 打开后是正常应用：**Dock 有图标**、可 Cmd-Tab 切换，窗口内即网站前台全部功能。
- 点左上角**红色关闭钮**：默认**缩小到系统托盘**（菜单栏右上角图标），Dock 图标消失、
  程序留在后台继续同步终端；想改成「关闭就退出」，在托盘**右键菜单**取消勾选
  「关闭时最小化到托盘」即可。
- 托盘图标：**左键**打开/切回窗口（Dock 图标随之恢复）；**右键**菜单 ——
  - `● 已连接 · 待信任/已信任`（连接状态；配置错误会直接显示原因）
  - `显示窗口` / `在浏览器打开`
  - `关闭时最小化到托盘`（勾选=关窗进托盘，取消=关窗即退出）
  - `开机自启`
  - `监控范围`（勾选某终端 = 不监控它）
  - `退出`（彻底退出，停止同步）

**改登录用户名**：右键 `终端任务监控.app` →「显示包内容」→ `Contents/Resources/config.txt`，
把 `AM_USER=admin` 改成你的用户名，重启 App。

---

## Windows（`windows-app/`）

**安装**：双击 `安装.bat` —— 复制到 `%LOCALAPPDATA%\AgentMonitor`、建开始菜单快捷方式、启动。
（若弹「Windows 已保护你的电脑」：点「更多信息 → 仍要运行」。）

**用法**：
- 打开后是正常应用：任务栏有图标，窗口内即网站前台全部功能。
- 点右上角 **×**：默认**缩小到系统托盘**（右下角），任务栏图标消失、程序后台继续
  同步终端；托盘**右键菜单**取消勾选「关闭时最小化到托盘」即可改成关窗直接退出。
- 托盘图标：**左键**打开窗口；**右键**菜单与 macOS 相同。

**改登录用户名**：记事本打开 `%LOCALAPPDATA%\AgentMonitor\config.txt`，改 `AM_USER`，重启程序。

**卸载**：双击 `卸载.bat`（清掉程序、开机自启项、快捷方式）。

---

## 接入后：去网站信任本设备

首次接入时设备处于「待信任」，会话不会立刻显示（隐私保护）。
到 https://monitor.vita-llm.com/portal → 左下角头像 →「设备管理」→ 点你这台电脑的「信任」。
托盘菜单顶部从「待信任」变「已信任」后，会话就会出现。

- 只能看到**自己名下、已信任**的设备（`AM_USER` 决定归属哪个账号）。
- 无论窗口开着（前台）还是缩在托盘（后台），只要程序没退出，同步就一直进行。

## 安全提示

`config.txt` 里的 `AM_AGENT_TOKEN` 是设备接入令牌，别把整包发到公开渠道。
泄露了让管理员在服务器上轮换即可。
