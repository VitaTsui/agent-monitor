# 终端任务监控 · 移动端 App

基于 Capacitor 的原生外壳，加载线上响应式前台
（<https://monitor.vita-llm.com/portal>），包含前台**全部功能**：会话列表、
Claude Code 终端式对话流、暂停/中断/终止、发布任务、设备管理、设置等。
前台已做手机自适应（侧栏抽屉、单列、触摸友好）。

## Android（已打好安装包，开箱即用）

`dist/终端任务监控-android.apk` —— 直接装到任意 Android 手机：

1. 把 APK 传到手机（微信/网盘/数据线均可）。
2. 点开安装；首次会提示「允许安装未知来源应用」，允许即可。
3. 打开「终端任务监控」App，登录后即可使用全部前台功能。

> 这是 debug 签名包，个人/内部分发直接可用。要上架 Google Play 需用正式签名
> 重新打 release 包（`./gradlew assembleRelease` + 签名配置）。

## iOS（用 Xcode 打开编译）

本机已生成完整 iOS 工程（`ios/App/App.xcworkspace`）。iOS App 必须用你自己的
Apple 账号签名，步骤：

1. `open ios/App/App.xcworkspace`（用 Xcode 打开）。
2. 选中 App target → Signing & Capabilities → 选你的 Apple ID 团队（个人免费账号也可装到自己手机）。
3. 连上 iPhone，选它为目标设备，点运行（▶）即可安装。
4. 上架 App Store 需付费开发者账号 + Archive 上传。

> 本机 Xcode 命令行有个模拟器插件小故障（`IDESimulatorFoundation`），
> 不影响用 Xcode GUI 编译真机/上架；如需命令行编译，运行一次
> `sudo xcodebuild -runFirstLaunch` 修复即可。

## 工程说明

- 框架：Capacitor 7（`capacitor.config.json`）
- 加载方式：`server.url` 指向线上前台，App 始终显示最新界面，改前端无需重打包。
- 应用 ID：`com.vitahsu.agentmonitor`，名称：终端任务监控。

## 重新构建

```bash
cd mobile-app
npx cap sync                       # 同步配置到原生工程

# Android APK
cd android && ./gradlew assembleDebug
#   产物：android/app/build/outputs/apk/debug/app-debug.apk
#   需要 JDK 21 + Android SDK（ANDROID_HOME）

# iOS（在 Mac 上）
npx cap open ios                   # 打开 Xcode 后编译
```

## 与桌面客户端的区别

- **桌面客户端**（`clients/`）：跑在电脑上，负责**上报**本机 Claude 会话。
- **移动端 App**（本目录）：跑在手机上，负责**查看与控制**——它不上报会话，
  是前台的原生外壳。两者配合：电脑装客户端上报，手机装 App 随时随地看。
